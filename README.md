# 🏵️ Better-Hytale
Better Hytale is a modpack created to bring more variety and depth to the Hytale gameplay! <br/>

## 🌟 Features 
▫️QoL mods for a more comfortable and enjoyable experience; <br/>
▫️Procedurally generated dungeons with new challenges and rewards; <br/>
▫️A wide range of new activities (fishing, musical instruments, and more); <br/>
▫️Improvements to existing activities (such as farming); <br/>
▫️Unique variations of animals and enemies; <br/>
▫️Expanded block and decoration variants for building; <br/>
▫️And much more!
